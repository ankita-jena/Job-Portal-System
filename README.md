# 💼 Job Portal System

A full-stack Job Portal web application built with Spring Boot where employers can post jobs and job seekers can apply.

### ✨ Features
- **For Employer:** Post a Job, View Posted Jobs, Dashboard
- **For Job Seeker:** Browse Jobs, Search Jobs, Apply, Success Page
- **Authentication:** Login / Registration System
- **Tech:** Spring MVC + Thymeleaf Templates

### 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot, Spring MVC, Spring Data JPA
- **Frontend:** Thymeleaf, HTML, CSS
- **Database:** MySQL
- **Build Tool:** Maven (pom.xml)
- **IDE:** IntelliJ IDEA

### 📂 Modules
- `Job.java` - Entity
- `JobController.java` - Main Controller
- `templates/` - index, jobs, login, post-job, success
- `application.properties` - DB config

### 🚀 How to Run
1. Create DB `jobportal`
2. Update username/password in `application.properties`
3. Run `JobPortalApplication.java`
4. Open `http://localhost:8080/`
